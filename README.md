# 🎓 EduPath Europe — AI University Matcher

An AI-powered web app that matches international students 
with European Master's degree programs based on their 
academic profile, budget, and requirements.

## Features
- AI-powered matching via Groq API (Llama 3.3 70B)
- Filters: GPA, country, English proof, budget, requirements
- Export results to Excel / CSV
- Match scoring with color grading
- One-click application portal links

## Tech Stack
- Vanilla HTML / CSS / JavaScript
- Groq API (Llama 3.3 70B)
- SheetJS for Excel export
